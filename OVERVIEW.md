Auto Session Title renames Paseo sessions after a period of idle time. It reads several rounds of a conversation and writes a short sidebar title in the form `MMDD｜type｜topic`, for example `1122｜design｜sidebar alignment`. The date prefix comes from the session creation time in Asia/Shanghai and never changes in later turns.

When a turn finishes, the plugin waits for the configured idle delay, then collects the first user message and the most recent user and assistant messages from the session timeline. It passes that text, the original title, and the configured prompt to the local `pi` CLI. The model named by your Pi configuration returns a title; the plugin parses it and writes it back through `paseo agent update`. If the conversation is only a greeting or does not contain enough information, the plugin keeps the existing title.

Requires Paseo 0.15.0 or later and an installed, authenticated `pi` CLI on the daemon host. The plugin finds `pi` and `paseo` on the daemon's command path by default and also checks common user and system install locations. Set `PASEO_AUTO_TITLE_PI_BIN` or `PASEO_AUTO_TITLE_PASEO_BIN` in the daemon environment when the commands live somewhere else. No account, cloud permission, or extra plugin is needed.

The settings page controls the idle delay, model source (Pi default, the current session's model, or a fixed model ID), a fully editable naming prompt, and whether to sync the visible workspace title so renamed sessions also appear with the new name in the sidebar. `{MMDD}` in the prompt is replaced with the session creation date. The page also offers an immediate scan of existing sessions and an action to unlock sessions whose titles were changed by hand.

The configured Pi model receives user and assistant message text, the original title, and the naming prompt to generate a title. Which provider handles that text depends on the local Pi configuration. The plugin only changes session titles and, optionally, the workspace display title. It does not change conversation content, project names, project ownership, ordering, pinned state, or archive state. State is stored on the daemon host under `~/.paseo/plugin-data/auto-session-title/`, and settings under `~/.paseo/plugin-settings/auto-session-title/`. The plugin runs unsandboxed on the daemon, so install it only from a source you trust.
